# Портфолио — Алексей Шуклин

Статический сайт без сборки: HTML + CSS + немного JS. Тёмная тема, плиточная система по мотивам
apple.com, eduardoduccigne.co и galimovilnur-portfolio.ru: короткое центрированное высказывание,
скруглённые плитки без обводок, пилюли вместо кнопок и тегов, один акцентный цвет — только для главного действия.
Принципы записаны комментарием в начале `assets/styles.css`.

После правок стилей поднимите версию в ссылках `styles.css?v=4` / `main.js?v=4` во всех 5 HTML-файлах,
иначе посетители увидят закешированную версию.

```
index.html              главная: hero, кейсы 2×2, подход, лидерство, опыт, контакты
cases/mes-metiz.html    главный кейс
cases/marketplace.html
cases/tasklets.html
cases/allforms.html
assets/styles.css       дизайн-система (токены цвета и скруглений в :root)
assets/main.js          лайтбокс, оглавление кейса, анимации, часы Москвы в подвале
assets/img/portrait.jpg фото (тонировка — фильтрами в CSS)
```

Режим черновика удалён: жёлтых пометок больше нет, сайт готов к публикации.

## Что стоит перепроверить

Блоки «Как я рассуждал», формулировки «Как мерили» и «Оговорка» у метрик дописаны по логике кейсов —
проверьте, что они совпадают с тем, как было на самом деле. На собеседовании спросят про каждую цифру.

Расхождения между источниками:
- доступность MES: в заметке и на Tilda **8,4**, в последнем CV **8,6**;
- стабильность MES: в заметке **6,8**, в CV **6,7**.

## Перед публикацией

- [ ] Картинки сейчас грузятся с CDN Tilda. Перед удалением сайта на Tilda скачайте их в `assets/img/`:
  ```bash
  mkdir -p assets/img && grep -oh 'https://static.tildacdn.com/[^"]*' index.html cases/*.html | sort -u | while read u; do curl -sSL -o "assets/img/$(basename "$u")" "$u"; done
  ```
  и замените адреса в HTML.
- [ ] `og:image`: сделайте обложку 1200×630 с именем и уровнем.
- [ ] CV лучше положить рядом с сайтом как `cv.pdf` вместо ссылки на Яндекс Диск.
